QUICK START (5 MINUTES):
========================

1. Build MaskPlace Docker Image:
   ─────────────────────────────
   cd /home/ubuntu/vnet/Optimize-Rouitng-and-Placing-on-VLSI/Thesis/MaskPlace
   bash build-maskplace-image.sh

   ✓ Creates: maskplace:latest
   ✓ Installs: PyTorch, gym, matplotlib, tqdm, protobuf
   ✓ Base: NVIDIA CUDA 11.8 runtime


2. Create Container (Mounts volumes):
   ───────────────────────────────────
   bash docker-run-maskplace.sh run

   ✓ Container name: maskplace_dev
   ✓ Mounts:
     - /MaskPlace       ← /home/ubuntu/.../MaskPlace
     - /DREAMPlace      ← /home/ubuntu/.../DREAMPlace (for integration)
     - /nthu-route      ← /home/ubuntu/.../nthu-route (for integration)

   ✓ Restart policy: unless-stopped (persistent)
   ✓ GPU support: --gpus all


3. Run MaskPlace:
   ───────────────
   # From host
   bash run-maskplace.sh adaptec1

   # Or interactive in container
   docker attach maskplace_dev
   cd /MaskPlace/maskplace
   python PPO2.py --benchmark adaptec1


DATA PERSISTENCE:
=================

✅ ALL DATA PERSISTS because:

   1. Host path mounted as Docker volume
      /home/ubuntu/.../MaskPlace ← /MaskPlace (bidirectional)

   2. Any file created in container is saved to host
      Example:
      - /MaskPlace/maskplace/tb_log/  ← visible on host
      - /MaskPlace/maskplace/*.pt     ← models persist

   3. Container restart or stop does not affect data
      docker stop maskplace_dev    ← container stops
      ls /home/ubuntu/.../MaskPlace/ ← data still there!

   4. Multiple sessions share same data
      Session 1: Train model
      Session 2: Test model (using same trained weights)

COMMON ISSUES & SOLUTIONS:
==========================

Issue: "Image maskplace:latest not found"
  Solution: bash build-maskplace-image.sh

Issue: "Container already exists"
  Solution: bash docker-run-maskplace.sh start

Issue: "GPU not detected in container"
  Solution: docker exec maskplace_dev nvidia-smi
           Rebuild: bash build-maskplace-image.sh

Issue: "Out of GPU memory"
  Solution: bash run-maskplace.sh adaptec1 --pnm 64

Issue: "Data lost after container restart"
  Solution: This SHOULD NOT happen with proper volume mounting
           Check: docker inspect maskplace_dev | grep Mounts
           Verify: ls /home/ubuntu/.../MaskPlace/
